# SpotEye

## Ascend NPU training

Use the Python environment provided by the
`pytorch_v1.1:2.4.0-npu-py310-ubuntu22.04-aarch64` image with its matching
`torch`, `torch_npu`, CANN runtime, and PyTorch 2.4-compatible torchvision
(0.19 series, with working CPU ops). The CUDA pins in `environment.yaml`
describe a different environment. Build the Detectron2 CPU extension against
the image's PyTorch if you need to install it from source.

Verify the runtime in the training container:

```sh
npu-smi info
python -c 'import torch, torch_npu; print(torch.ones(2, device="npu:0").sum().item())'
```

After preparing the dataset and weights, start with one NPU:

```sh
python tools/train_ps_net.py --num-gpus 1 --config-file configs/person_search/spoteye.yaml
```

`--num-gpus` counts NPUs on this branch. Multi-device training uses HCCL
and uses Gloo for gathering Python evaluation objects. Standard batched NMS
and ROIAlign run on the CPU for torchvision compatibility and return results
to the NPU. ROIAlign keeps the autograd path across the device copies.

SpotEye is a depth-assisted framework for text-based person search. The code
uses CUHK-SYSU-TBPS and PRW-TBPS RGB images together with grayscale monocular
depth maps generated by the official Depth Anything V2 model.

> The public SpotEye and DepthModelLite files currently preserve model
> structure and interfaces only. The withheld implementation will be released
> after the associated paper is published.

## Requirements

The main environment is described in `environment.yaml`. The principal runtime
dependencies are:

```text
Python 3.10
PyTorch 2.5.0
torchvision 0.20.0
CUDA 12.1
Detectron2 0.6
```

Install the additional dependencies required for depth generation:

```bash
pip install -r third_party/depth_anything_v2/requirements.txt
```

## Dataset preparation

Download [CUHK-SYSU-TBPS and PRW-TBPS](https://github.com/Dacun/Text-based-Person-Search)
and arrange the original RGB images as follows:

```text
Data/
├── cuhk_sysu/
│   ├── annotation/
│   ├── Image/
│   │   ├── SSM/          # original CUHK-SYSU RGB images (*.jpg)
│   │   └── Depth/        # generated grayscale depth maps (*.png)
│   ├── CUHK-SYSU-TBPS_train
│   └── CUHK-SYSU-TBPS_test
└── PRW/
    ├── annotations/
    ├── frames/           # original PRW RGB images (*.jpg)
    ├── Depth/            # generated grayscale depth maps (*.png)
    ├── PRW-TBPS_train
    └── PRW-TBPS_test
```

### Download the official Depth Anything V2 checkpoint

The Depth Anything V2 source is vendored under
`third_party/depth_anything_v2`, but pretrained weights are intentionally not
redistributed. Download an original checkpoint from the Depth Anything V2
authors:

| Encoder | Official checkpoint |
| --- | --- |
| `vits` | [Depth-Anything-V2-Small](https://huggingface.co/depth-anything/Depth-Anything-V2-Small/resolve/main/depth_anything_v2_vits.pth?download=true) |
| `vitb` | [Depth-Anything-V2-Base](https://huggingface.co/depth-anything/Depth-Anything-V2-Base/resolve/main/depth_anything_v2_vitb.pth?download=true) |
| `vitl` | [Depth-Anything-V2-Large](https://huggingface.co/depth-anything/Depth-Anything-V2-Large/resolve/main/depth_anything_v2_vitl.pth?download=true) |

The examples below use the `vitl` checkpoint. The `--encoder` value must match
the downloaded checkpoint. Do not add checkpoints to this repository. Refer to
the [upstream licensing notice](third_party/depth_anything_v2/README_UPSTREAM.md#license)
before selecting or redistributing model weights.

### Generate grayscale depth maps

Always generate depth from the original, undegraded RGB images. The provided
script performs per-image normalization and writes one-channel, 8-bit grayscale
PNG files while preserving each source filename stem and spatial resolution.

For CUHK-SYSU-TBPS:

```bash
python tools/generate_depth_maps.py \
  --encoder vitl \
  --checkpoint checkpoints/depth_anything_v2_vitl.pth \
  --input-dir Data/cuhk_sysu/Image/SSM \
  --output-dir Data/cuhk_sysu/Image/Depth
```

For PRW-TBPS:

```bash
python tools/generate_depth_maps.py \
  --encoder vitl \
  --checkpoint checkpoints/depth_anything_v2_vitl.pth \
  --input-dir Data/PRW/frames \
  --output-dir Data/PRW/Depth
```

The filename correspondence must remain exact:

```text
Data/cuhk_sysu/Image/SSM/s1.jpg  -> Data/cuhk_sysu/Image/Depth/s1.png
Data/PRW/frames/c1s1_000001.jpg  -> Data/PRW/Depth/c1s1_000001.png
```

Existing depth maps are skipped by default. Pass `--overwrite` only when they
must be regenerated. CUDA is selected automatically when available; use
`--device cpu` to force CPU inference.

## Training


```bash

  --resume \
  --eval-only
```
